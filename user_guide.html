Initial Setup — Connecting Your Google Sheet

Match Tracker Pro runs as a web app that reads from and writes to your Google Sheet. Before you can log a single match, you need to deploy an Apps Script web app from your spreadsheet and paste its URL into the tracker. This is a one-time process — once it's connected, you won't need to touch the spreadsheet again.

📱 Setup Screen

When you first open Match Tracker Pro, you'll land on the Connect Your Google Sheet screen. This is where the handshake between the app and your data happens. Follow the four steps below exactly as listed — the sequence matters.

1

Open Apps Script in your Google Sheet

Open your Google Sheet and navigate to Extensions → Apps Script in the top menu bar. This opens the Apps Script editor, which is where the web app lives. If you've never been here before, you'll see a code editor — that's expected. You don't need to modify anything in the script itself.

2

Create a New Web App Deployment

In the Apps Script editor, click Deploy → New Deployment in the top-right corner. A dialog will appear. Click the gear icon (⚙) next to "Select type" and choose Web App from the options. This tells Google you want to publish the script as a publicly accessible web service.

3

Configure Permissions and Deploy

In the deployment settings, set Execute as to Me and Who has access to Anyone. Then click Deploy. Google will prompt you to authorize the app — click through the authorization flow and grant the requested permissions. Once authorized, you'll be shown the Web App URL. Copy that URL — you'll need it in the next step.

Note on authorization: Google may display a warning that the app isn't verified. This is expected for personal Apps Script projects. Click Advanced → Go to [project name] (unsafe) to proceed. The script only accesses your own spreadsheet data.
4

Paste the URL and Tap Get Started

Return to Match Tracker Pro. Paste the Web App URL you just copied into the WEB APP URL field on the setup screen — it will look something like https://script.google.com/macros/s/.... Once pasted, tap Get Started → to complete the connection. If the URL is valid, you'll be taken directly to the Dashboard.

You only do this once. After setup, the app is your primary interface for everything — logging matches, reviewing history, and analyzing performance. There's no need to return to the spreadsheet unless you want to view the raw data directly.
Something went wrong? If tapping Get Started doesn't connect successfully, double-check that you copied the full URL (it should start with https://script.google.com/macros/s/ and end with /exec). Also confirm the deployment permissions were set to Execute as: Me and Who has access: Anyone.

Dashboard

The Dashboard is where the scoreboard lives. Every time you open the app, this is your first view — a full read on your performance without having to dig through individual matches. Think of it as your pre-match warm-up: a quick scan tells you exactly where your game stands.

Match History

Match History is your complete match archive — every result, every score, every partner. More than a log, it's a filtering system that lets you slice your record by opponent, partner, match type, time period, and more. Every filter you apply instantly recalculates the statistics panels above the match list, so you're always seeing numbers that reflect exactly the matches on screen.

📋 Match History Page
Search and Filtering

At the top of the Match History page, two search fields let you narrow the match list immediately:

Opponent
search		Type any part of an opponent's name to filter to matches involving that player. Partial matches work — typing "Kim" will surface all matches against anyone with "Kim" in their name.
Partner
search		Same behavior, but filtering by your partner's name. Leave this blank to include matches with all partners (or no partner, in singles).

Tap More Filters to expand additional filtering options. Multiple filters can be applied simultaneously — for example, you can search for all doubles matches in the Spring season at Away venues over the last two years. Tap Clear Filters in the top-right to reset everything back to the full match list.

Combining filters is where the real insight lives. Filtering to a specific opponent over multiple seasons can reveal whether you've improved against them. Filtering to Away + Night can show whether your game suffers in those conditions.

Match Entry

Match Entry is where every match gets recorded. The form is split into two panels — Match Basics on the left for the core match data, and Other Match Details on the right for contextual information. Only a handful of fields are required; the rest add depth to your analytics over time. The more you fill in, the more the Dashboard can tell you.

Submitting and Clearing

Once you've filled in the fields, click Submit Match in the bottom-right corner to save the record to your Google Sheet. The form will confirm a successful submission and reset for your next entry.

If you want to start over without saving, click Clear — this resets all fields back to their defaults without submitting anything.

CHANGE THIS Before you submit: Make sure Opponent 1, Type, Date, and at least Set 1 scores are filled in. These are the minimum required fields. A match submitted without a score cannot be accurately tracked in your win/loss record.

Valid Entries

Valid Entries is the control room for your dropdown lists. Every selectable option that appears in Match Entry — partners, seasons, leagues, levels, lines, surfaces, and playoff rounds — is managed here. If something isn't in a list, it won't show up as an option when logging a match. This page also houses the Performance Thresholds settings that control color-coding throughout the app.

⚙️ Valid Entries Page
Managing Your Lists

Valid Entries displays nine category panels in a grid layout. Each panel shows the current entries for that category, a count of how many exist, and controls for adding or removing entries. Categories that have more entries than fit in the visible preview show a Show X more link — click it to expand the full list.

Category What It Controls
PartnersAll doubles partners selectable in Match Entry. Add a partner here before logging your first match with them.
SeasonsSeasonal labels used to group matches — typically Winter, Spring, Summer, and Fall, but customizable to match your league calendar.
LeaguesThe league or organization each match is played under (e.g., ALTA, T2, Ultimate). Add a new league here when you join a new team or program.
LevelsCompetitive levels or ratings used in your leagues (e.g., A-8, B-1, B-2). Add new levels as your rating changes or new divisions become relevant.
Match Types

The match formats available in the Type dropdown — Singles, Doubles, Mixed Doubles, and any others you want to track.

Note: For optimal results, include the word "Doubles" in any type of doubles you add to this list. For example, Men's Doubles, Mixed Doubles, Senior Mixed Doubles, etc.

LinesCourt line numbers used in team matches (e.g., Line 1, Line 2). Add or remove lines to match the structure of your team's format.
Home / AwayLocation designations — Home, Away, and Neutral are the defaults. These power the Home/Away breakdown on the Dashboard.
SurfacesCourt surfaces — Hard (Outdoor), Clay (Outdoor), Hard (Indoor), and any other surface types relevant to your match venues.
Playoff RoundsThe rounds available when logging a playoff match — for example, Round 1, Quarterfinal, Semifinal, Final, and so on.
Adding and Removing Entries

To add a new entry to any category, type the value into the Add new… field at the bottom of that category's panel and click + Add. The new entry will appear in the list immediately and become available as a dropdown option in Match Entry.

To remove an entry, click the ✕ icon to the right of any existing entry. Removing an entry does not delete historical match data that was logged with that value — it only prevents it from appearing as a selectable option going forward.

Before removing an entry, make sure you're not actively using it for upcoming matches. For example, removing a partner mid-season means you'll need to re-add them if you want to log future matches with them via the dropdown.
Performance Thresholds

At the bottom of the Valid Entries page is the Performance Thresholds section. These settings control the color-coding system used throughout the app — in the Performance Breakdown table on the Dashboard and in Match History statistics — to give you an at-a-glance read on how strong or weak a particular result is.

Great (Green) ≥ 55%
Average (Orange) 45–55%
Poor (Red) ≤ 45%

The defaults are set at 55% for Great (green) and 45% for Poor (red). Any win percentage at or above the Great threshold displays in green; at or below the Poor threshold displays in red; anything in between displays in orange.

To adjust the thresholds, change the values in the Great (Green) ≥ and Poor (Red) ≤ fields and click Save. The color-coding across the entire app will update to reflect your new settings immediately.

Calibrating to your level: If you're a competitive player with a naturally high win percentage, raising the Great threshold to 65% or 70% gives you a more meaningful green benchmark. If you're newer to competitive play, lowering it to 50% might be more motivating and accurate to your progress.

Importing Matches from Another Spreadsheet

The Match Import tool allows you to quickly bring existing tennis data into Match Tracker Pro from another spreadsheet. This is the only reason you ever need to access the Google Sheet directly — and once you complete the import one time, you never need to use the spreadsheet again.

📥 Match Import Tool
Where Match Imports Happen

All imports are performed on the Match Import tab inside your Google Sheet.

One-time setup: Once your historical matches are imported, you can go right back to using Match Tracker Pro normally. You never need to return to the spreadsheet unless you want to import additional historical data later.
🎾 Need Help Importing Existing Match Data? Optional Service

Already have years of tennis data in another spreadsheet? We can handle the import process for you.

Our data import service reformats your existing spreadsheet, validates the data, and imports everything directly into Match Tracker Pro so your full match history is ready to go from day one.

Pricing depends on spreadsheet size and formatting complexity. Most imports fall between $20–40.

Step 1 — Reformat Your Existing Spreadsheet

The easiest and most reliable way to import matches is to reorganize your existing spreadsheet so the columns match the exact layout of the Match Import tab.

  • Move columns in your original spreadsheet as needed so they line up correctly.
  • Add any missing columns required by Match Import.
  • If you do not have data for a particular column, simply leave it blank.

  • Playoff (Column K) and Retired (Columns V and W) must contain either TRUE or FALSE values.

Formatting matters. Match Import expects the columns to appear in the exact same order as the Match Import tab.

Step 2 — Paste Your Match Data

Once your original spreadsheet matches the Match Import layout:

  1. Copy all match rows from your original spreadsheet.
  2. Open the Match Import tab.
  3. Click cell A4.
  4. Press CTRL + SHIFT + V to paste values only.
Use CTRL + SHIFT + V. This pastes raw values only and avoids bringing over formatting or formulas that can interfere with the import process.
Valid Entries During Import

There is no need to manually add entries on the Valid Entries page before importing.

Any leagues, levels, partners, surfaces, playoff rounds, or other values not already present in Valid Entries are automatically detected and added during the import process.

After analyzing data, the Import Wizard displays all entries that will be added automatically.

Need to adjust an entry? Click the Pencil icon beside any detected entry to edit or correct it before importing the matches.
Step 3 — Run the Import Wizard

After your data has been pasted:

  1. Click the Import Matches button.
  2. The Import Wizard opens.
  3. Click Analyze Data to scan the data for issues.

If errors are found:

  • Rows with issues are highlighted in red.
  • Fix the highlighted data problems.
  • Click Re-analyze to check the updated data again.
Step 4 — Import the Matches

Once the data is ready:

  1. Click the Import button.
  2. All error-free rows are imported automatically.
  3. Rows that still contain errors are skipped and remain highlighted in red.

You can optionally fix the remaining rows and import them afterward.

Refresh Match Tracker Pro after importing to immediately see all imported matches and updated statistics.
