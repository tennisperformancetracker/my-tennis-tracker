Welcome to Match Entry
Connect this app to your Google Sheet tracker in 4 quick steps. You only need to do this once.
1

Open your copied Google Sheet and click Extensions → Apps Script

2

Click Deploy → New Deployment. Click the ⚙ gear icon and select Web app

3

Set Description to "Match Entry". Set Execute as to "Me". Set Who has access to "Anyone". Click Deploy and authorize when prompted. Copy the URL.

4

Paste that URL in the box below and tap Connect
